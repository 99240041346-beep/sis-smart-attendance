# KARE ONE — SIS Smart Attendance

Clean rebuild starting from the foundation.

## Build order
1. Core project + reliable API health
2. Authentication and role routing
3. Student / Faculty / Admin portal shells
4. QR attendance (first real attendance test)
5. Face verification
6. Location + distance verification
7. Anti-proxy and audit controls
8. Production database integration and reporting

The project is intentionally rebuilt in small, testable phases. No later attendance security layer is enabled before the previous phase is verified.
